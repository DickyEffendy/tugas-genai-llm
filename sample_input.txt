Machine learning adalah cabang kecerdasan buatan yang memungkinkan komputer mempelajari pola dari data tanpa harus diprogram dengan aturan khusus untuk setiap situasi. Proses umum machine learning meliputi pengumpulan data, pembersihan data, pemilihan model, pelatihan, evaluasi, dan penggunaan model untuk membuat prediksi. Pada supervised learning, model belajar dari contoh yang memiliki label, sedangkan unsupervised learning mencari pola pada data tanpa label. Kualitas dan representasi data memengaruhi hasil model. Model yang baik perlu dievaluasi pada data yang tidak digunakan selama pelatihan agar kita dapat menilai kemampuannya pada situasi baru. Machine learning dapat digunakan untuk klasifikasi email, rekomendasi produk, prediksi permintaan, dan deteksi anomali. Namun, hasilnya tidak selalu benar; bias pada data, data yang tidak lengkap, dan perubahan pola di dunia nyata dapat menurunkan akurasi.
